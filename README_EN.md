# re-phigros

## Description

**The main project of RE:Phigros a.k.a. Phi:Re**

## Code Standards

**Strictly**  follow the standard code style of C#.

- Use camelCase for variable names and parameter names
- Always use braces, even when they're not strictly necessary
- Indent with four spaces, not tabs
- Use `var` when possible to reduce clutter
- Keep lines under 100 characters long

**Never** use `public` to expose a member to Unity, use `[SerializeField]` instead.

## Git Standards

**Never** commit directly to the `master` branch.

**Never** try to merge a branch without issuing a pr.
